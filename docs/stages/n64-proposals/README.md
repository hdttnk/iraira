### 確認済み・推定・不明

- **確認済み（映像内）**: 上表の主要な形の存在と、おおまかな登場順。3風車は独立した3部屋ではなく、外周がつながった区画に見える。まゆげには丸い正弦波ではなく、短い平坦部と斜面がある。3:49の巻き返しは現在の細かなS字とは明らかに異なる。
- **推定**: 全座標・縮尺・通路44px・曲率・障害物間隔。1stの分岐を省いた接続。2ndの横3通過路という読み取り。3rdの外周を円で近似した境界、下分岐の正確な接続、ひねりを交差のない平面へ展開した形。これらは映像を直接トレースした実測値ではない。
- **不明 / 据え置き**: うずまき中心の正確な戻り経路（現行案を暫定維持）、立体の奥行きと上下関係、縦折り返しの厳密な本数、プレスの正確な台数・形・周期・位相。図の5本の縦通過路は検討用の仮配置。プレスは下記の追記により片側1物体へ修正。
- **風車の羽根数に注意**: 3:19の描画は6方向に見えるため案は6枚。一方、画面右の投稿者解説には8枚とある。テレビ版の説明なのかを含め今回の観察だけでは解消できないので、N64版の確定仕様とはしない。速度・回転方向・位相も本家と一致するという検証はしていない。
- **2D化の限界**: N64の立体ひねりとカメラの視点変更を平面の丸操作でそのまま再現できない。今回は特徴的な巻き返しを展開した案。テレビ版とN64版を同一形状とみなさない。

## 成果物

## 再生成

プロジェクト直下で実行（Node/tsxおよびPillowが必要）:

```sh
node --import tsx scripts/export-n64-proposals.ts
python3 scripts/render-overview.py first docs/stages/n64-proposals
python3 scripts/render-overview.py second docs/stages/n64-proposals
python3 scripts/render-overview.py third docs/stages/n64-proposals
```
