## 確認済み・推定・不明

**確認済み（資料内の記述と図を確認した意味）**：ヘアピン→うずまき→奥の細道→休憩→いろは坂→カーブひねり→フラッシュ→まゆげ。渦の中心で回り方が反転する。いろは坂は5段。前半曲線・後半直線主体。資料のTVルールは全体60秒、前半30秒以内、休憩で時計停止。

**推定**：図から読める大まかな左右・上下配置。中心線、各曲率、渦の巻き数・半径、ひねりの投影、障害物間の距離はゲーム用に構成した仮値。資料のピクセルを実寸と見なしていない。

**不明**：公式設計図、実物の各寸法、詳細な奥行き、収録回による変形、N64スーパーとの点ごとの差。細道幅はS1が5cm、S2が4cmで一致せず、確定しない。ここを架空の寸法で補っていない。

## 実装と調整

| 識別 | 実装 | 根拠・差異 |
|---|---|---|
| 01 | 大きく上下するヘアピン | S1図の左側構成。往復が結合しない間隔を確保。 |
| 02 | 内向きに入り中心でUターン、逆回りに外へ出る二重渦 | S1/S2の方向反転を採用。渦の中心間隔80px以上を目安とした独自寸法。 |
| 03 | 長い水平の細道 | S1図の低い連絡路。人体の低姿勢は2Dでは再現しない。 |
| R | 中間休憩、時計停止 | 休憩領域の中心座標に入ると時計停止、出ると再開。接触失敗は残る。TVの絶縁テープによる接触許可までは実装しない。 |
| 04 | 左右へ5段の折返し | 5段の順序と形を採用。段ごとの幅の違いは未再現。 |
| 05 | N字の中央にS字 | 立体ひねりを2Dの平面曲線に置換。棒の回転・奥行き入力を新設していない。完全再現ではない。 |
| 06 | 稲妻状の二つの折れ | S1図・S2の特徴を採用。短い折返しも隣の通路と分離。 |
| 07 | 2山の小さな曲線 | つながりまゆげの終盤配置。形状・振幅は仮値。 |

最初の制限は **180秒、前半90秒**。前半は休憩到達までに全体設定の半分を消費すると失敗。全体時間を変更すると前半も同比率で変わる。休憩は時間を加算せず消費を止める。初回移動までは従来どおり計測しない。練習・任意座標で休憩より右から開始した場合、前半制限を通過済み扱いにする。休憩から逆戻りしても領域を出ると計測は再開する。

180秒は本家の値ではない。無敵なしの標準自動操作で全体約112.18秒だったため、精密操作の評価余裕を持たせた仮値。TVの半分ずつの考え方は維持し、実時間はスマホ向けに延長した。基準幅44px、調整範囲36〜52、半径6px、操作曲線・最高速度125px/sは1stと同じ。元資料の狭さ比率は今回まだ反映していない。

描画と当たり判定は1stと同じ結合ポリゴン。固定ステップと軌跡判定を継続。風車・プレスはスーパーに混入させていない。

## 練習・開発・プレビュー

`?stage=second` で直接選択、または上部「練習」のステージから2nd。練習点はスタート、ヘアピン、うずまき、細道、休憩、いろは坂、N字ひねり、フラッシュ、まゆげの9地点。`?stage=second&dev=1` で開発者設定。8秒の自動プレビューと2回目のスキップを共有。半径・幅・無敵・時刻・速度変更を維持。

## 追加依頼：失敗時の破裂演出

すべてのステージで接触・時間切れ・前半時間超過の失敗に共通適用。丸を消し、18個の白い粒と拡がる輪を約0.4秒で消す。失敗表示は180msだけ遅らせて演出を見せ、下のリトライ・Rは待たずに使える。判定やシミュレーションに粒子を参加させない。
