# 試験コースの現代的ビジュアル試作（旧パネル案）

**現在の試験コースは [銅線案](prototype-copper.md) に変更済み。このページは前案の比較記録。**

対象は `?stage=prototype` のみ。仮のビジュアル見出しは ARC RUN。1st〜3rdは従来の白黒表示を維持。

## 表現

- 暗いネイビーの金属パネル、低コントラストの継ぎ目と留め具。
- 通行可能な床は暗く、実境界にシアンの細線を配置。幅広い発光は低透明度の装飾で、接触境界は中心の細線。
- 可動障害物はアンバーの縁と金属色の面、内部の細い継ぎ目で識別。
- プレイヤーは既存の半径の円と薄いミントの光。光の外周は当たり判定ではない。
- スタートのドック、ゴールのEXITゲート、方向の目印。
- 上部HUD、開始カード、スティックと操作エリアを同じ色調へ変更。スティックの寸法は維持。
- 失敗時は既存の破裂動作にミント・アンバー・白の色を適用。

## 実装・維持事項

`src/prototype-renderer.ts` に描画を分離。床と明るい境界は試験コースの通路矩形の和集合から生成。壁の留め具は衝突壁の内部にのみ描画。既存の試験ステージデータ・操作・衝突・カメラ追従係数・タイマーは変更していない。

色・材質・UIのCSSは `data-skin=modern` で試験コースだけに適用。ステージ切替で解除する。新しい画像アセットや外部フォント、3D物理、追加ライブラリは導入していない。現代風の2D表現で、立体的にカメラを回す3D化はしていない。

## 確認

- `pnpm build`: 型チェック・本番ビルド。
- `node tests/browser-modern.mjs`: 390×844のタッチ画面で開始・移動・即停止、風車/プレスの練習開始、4画面サイズ、通常ステージへ切替時の見た目リセット。ページエラーなし。
- `node tests/browser.mjs`: 既存のタッチ・マウス・キーボード・練習・開発者設定の回帰確認。
- `node tests/browser-touch-guards.mjs`: タッチ終了・連続リトライ・拡大防止の回帰確認。
- スクリーンショット4枚（開始カード・通常プレイ・風車・プレス）を目視し、プレイヤーと壁/障害物の識別・UIの収まりを確認。
