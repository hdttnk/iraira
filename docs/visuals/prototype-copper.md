# 試験コース / 銅線のビジュアル

ユーザーの補足に合わせ、「金属パネルの通路」案から、イライラ棒のコンセプトに沿った銅線コースへ修正。

- ほぼ黒の背景。床・壁の面塗り分け、格子、パネル、留め具を撤去。
- コースの両側を銅色の線で描画。濃い銅色、明るい銅色、細いハイライトを重ねて厚みと光沢を表現。
- 線は元の境界から壁側へずらして描き、通路側の縁が既存の当たり判定に対応する構造。発光・影は装飾。
- 風車・プレスも銅色の表面へ変更。実際の障害物矩形の内側にハイライトを描く。
- HUD・スティックも黒と暖色へ統一。仮のARC見出しを撤去してPRECISIONに戻した。
- 試験コースのみ。操作、移動速度、プレイヤー半径、コース形状、衝突ロジックは変更なし。

`pnpm build`（型チェック含む）、`tests/browser-modern.mjs`、`tests/browser.mjs` が成功。縦画面の開始・風車・プレスの画像を確認し、4画面サイズ・即停止・練習・開発者設定・通常ステージへの表示切替も確認。iPhone Safari実機の視認性・動作速度は未確認。

画像: [prototype-copper.png](prototype-copper.png)。前のパネル案は `prototype-modern.png` と `prototype-modern.md` に比較記録として保持。

## 1st〜3rdへ適用

ユーザー確認後、同じ銅線表現を全ステージへ適用した。描画を `src/copper-renderer.ts` に共通化。1st〜3rdは `Simulation.geometry` の実際の閉じた境界を直接使用し、試験コースは従来どおり通路矩形の和集合を使用する。コース形状と衝突データの変更なし。

ヘアピンの曲線、2ndの片側細道の段差、3rdの風車室・中心・休憩・4プレス・小部屋を維持。プレイヤー、可動物、破裂演出、HUD・スティックも全ステージで銅色/暖色に揃えた。

本番ビルド/型チェック、`tests/browser-copper-stages.mjs`、`tests/browser-third.mjs` が成功。1st〜3rdの練習地点、細道通過・即停止・接触・リトライ、3rdのプレビュー/休憩/風車/プレス/開発者設定、4画面サイズを検証。4枚の新しいスクリーンショットを目視確認。ページエラーなし。iPhone Safari実機の見やすさ・動作速度は未確認。
